# EurekaLife Mac 产品原型

> 类型：当前产品原型说明 · 更新：2026-11-02 · 范围：HTML 交互设计，非 Swift 功能验收

入口：[index.html](index.html)。纯 HTML / CSS / JavaScript，双击即可打开，也可通过本地 HTTP 服务访问。

## 代码依据

基于 brightman/vessel 的 dev-desktop 分支，e4c46e3。

- CompanionView.swift：概览、模型库、已配对设备、隐私、配对弹层与撤销确认。
- CompanionModel.swift：下载、校验、加载、卸载、服务开关、网络及授权状态。
- CompanionStyle.swift：石墨灰 #20272e、灰蓝 #335f83、浅灰 #f5f5f7、侧栏 #edf0f3、成功色 #34745e。
- ModelCatalog.json：仅展示实际固定目录中的 Qwen3-4B / 1.7B 4-bit，版本与下载体积从清单生成 catalog.js。
- ModelRecommendation.swift：4B 推荐 16GB+，1.7B 推荐 8GB+。
- WiseLifeCompanionApp.swift：菜单栏快捷操作。

## 设计优化

保留原生四页结构，统一 iPhone 与官网的 EurekaLife 品牌、配色、圆角和细线图标。概览首张卡片合并设备配置和运行状态：Mac 型号、统一内存、硬盘总容量及可用空间、推理队列、首次响应、进程峰值内存；下方保留模型状态、设备连接和服务开关。模型库明确区分下载文件与加载到内存；卸载保留文件，删除文件需二次确认（原型建议的交互优化）。

配对始终不等于在线；不使用虚假的在线绿色指示。开关可开启服务，但只有模型加载、设备已配对且网络可用时才能模拟请求。当前页面以 M3 / 16GB 为演示配置，不读取访问者设备信息。

页面顶部的演示状态属于评审工具，非正式 App 菜单。可切换首次打开、日常使用、下载中、下载失败、网络不可达、内存压力、钥匙串授权。可以体验取消、校验、加载、卸载、删除、配对失效与重新生成、撤销、网络重试、模拟请求、菜单栏。

## 边界

所有状态仅保存在当前页面内存，刷新即重置。不调用模型、扫描网络、读取钥匙串、生成配对凭据、下载权重或储存真实记录。配对图形不可扫码，指标为明确标记的示例值。来源链接只在用户点击时打开官方模型页面。

LLM 沿用真实模型目录；ASR 新增 Whisper Small 候选与转写接口设计，尚未落入 Swift 代码。不加入云端回退或自动执行行动。知识库新增 Mac 录音交互演示，但不调用麦克风、不生成音频，也不执行真实转写。深色模式不加入本轮：当前 Swift 工程强制浅色。手机宽度布局仅方便原型评审，不表示 Mac App 支持 iPhone 运行。

## ASR / LLM 更新

使用 Resources/Assets.xcassets/AppIcon.appiconset/icon-128@2x.png 作为真实 App 品牌图标。
模型库增加 LLM / ASR 分类，概览显示两个 iPhone API 的就绪状态。

- LLM：现有 POST /v1/chat/completions，保留实际 Qwen3 模型目录。
- ASR：拟新增 POST /v1/audio/transcriptions，候选 Whisper Small；版本、文件大小、引擎和硬件需求待验证，不使用虚构容量。
- 两者共用设备配对与 TLS 授权，模型分别加载。ASR 要求服务开启、模型已加载、网络可达及已有配对设备才能模拟请求。
- 新增 iPhone「语音转写模型 → 附近 Mac」入口属于方案，非已实现状态。
- 音频经授权发送至 Mac，仅临时处理，完成／取消／失败后清理的机制需开发落实；不会自动把转写文本交给 LLM。
- 双模型内存驻留和请求调度仍需工程验证，原型不构成并行推理承诺。

检查：App 图标加载、ASR 下载／校验／加载／请求／返回结果、LLM 独立状态、服务暂停阻断转写、四种宽度无溢出。

## 知识库原型（2026-10-31）

打开 `index.html#knowledge` 或点击左侧“知识库”。三栏布局：导航 / iPhone 每日记录 / Ask AI。
支持日期浏览、当天搜索、类型筛选、展开全文、围绕单条记录提问、新对话、停止生成和引用回跳。
Ask AI 默认按问题查找示例资料，不随浏览日期强制限制范围；选择单条记录时显示明确范围，可取消。
示例日期为 2026-10-30、2026-10-31，其他日期展示空状态。数据、同步状态和模型回复均为演示，刷新页面不持久化。
知识库是新增产品设计；不代表现有 Mac App 已实现记录同步、存储或真实 Ask AI。
新增文件：knowledge.js、knowledge.css。截图：verification/knowledge.png、knowledge-mobile.png。
验证：Chromium 1500×1040 / 390×844，无页面脚本错误；测试了指定记录提问、引用回跳、搜索空状态、页面切换和窄屏无横向溢出。

导航调整：概览 → 模型库 → 知识库 → 隐私与说明。已配对设备合并到概览，保留设备列表、配对、撤销、钥匙串提示及连接帮助；连接摘要的“管理”滚动定位到该区域。已验证导航顺序、撤销配对、钥匙串场景及知识库切换。


## 概览与知识库交互（2026-11-02）

- **概览首块**：示例 MacBook Air / Apple M3、16 GB 统一内存、512 GB SSD / 128 GB 可用；同块展示运行状态。状态随服务暂停、模型未加载、请求处理中、网络不可达和内存压力场景更新，原底部运行卡片删除。硬件与性能数字均为示例。
- **Ask AI 展开／收起**：侧栏右上角可收起，记录区顶部可重新展开；记录区使用释放的宽度。保留草稿、已有对话和提问范围，生成中收起不会取消回复。“围绕这条提问”自动展开并聚焦输入框。切换到其他页面时，异步回复不会覆盖当前页面。
- **开始录音**：中间记录区新增入口；点击后显示录音中、计时、停止并保存，录音中禁止重复启动。切换页面再返回时继续显示状态。停止后在示例“今天”（2026-10-31）新增一条来源为“这台 Mac”的演示记录，带开始时间和时长；自动返回该日、清空搜索与筛选，避免新记录不可见。
- **演示边界**：不申请麦克风权限、不采集音频、不调用 ASR／LLM；保存只写当前页面内存。记录正文明确标明演示状态，不伪造录音内容。顶部“重置”清空演示录音、计时器、对话和草稿；刷新也会重置。

本地预览：在本目录执行 `python3 -m http.server 8791 --bind 127.0.0.1`，打开 [概览](http://localhost:8791/#overview) 或 [知识库](http://localhost:8791/#knowledge)。

通过 Chromium 检查：1500 / 1280 / 1024 / 900 / 768 / 390 / 320px 无横向溢出；展开收起、草稿保留、异步回复切页、录音开始／停止／重置均通过，1小时0分2秒的虚拟时钟检查通过。
