## 来源与运行方式

按用户指定，从 `EurekaMind/sourcecode/frontend-components` 移植实际源码，未用相似 CSS 重写替代。源目录部分文件是 iCloud 未下载占位，因此从本地 resident Git pack 提取提交 `f045b381ee8c8395524b1c424319ade9c3b5273b`；逐个核对提取 blob 与指定目录 Git index 一致。未访问远端以推断“最新版本”。

28 个源码文件及辅助文件（27 个保持原样，三栏组件有明确的本地适配）在 `src/components/standard/`，每个文件的 Git blob / SHA256 见 [来源清单](../src/components/standard/sources.json)。复制了源项目的 Mantine MIT 许可证 `MANTINE-LICENSE`；包装组件的源项目没有根 LICENSE，因此不把 Mantine 许可证解释为整个私有组件目录的另行授权。

| 范围 | 当前采用 |
| --- | --- |
| 框架与构建 | React 19.1.1、TypeScript、Vite；`index.html` 载入 `src/main.tsx` |
| 底座 | 官方 Mantine Core / Hooks / Dates 8.3.18 |

| 业务组合 | `src/components/ui.tsx`、`src/features/*`；概览进度条直接使用官方 Mantine Progress |
| 静态资料 | `src/demo.json` 转存旧原型合成数据；App 图标复制到 `public/assets/` |

CSS 层顺序为 `theme, base, mantine, components, utilities`，禁用 Tailwind Preflight。三栏组件增加 `showMenuCollapseButton`、`withAgent` 与 `retainMenuRail` 三个可选宿主参数，默认行为与上游一致；原始 sha256 / gitBlob 保留，本地版本单独记录 localSha256。其他组件源码保持不变；优先使用公开 props，余下差异使用公开 `classNames` 的静态 Tailwind 类。只在原生业务容器上使用普通 className。依赖锁定在 package-lock，规范与协作入口分别为 [ui-spec.md](ui-spec.md) 和 [AGENTS.md](../AGENTS.md)。

启动、构建、测试命令见 [README](../README.md)。浏览器入口仍是 `http://127.0.0.1:8791/#meetings`；`index.html` 不能再直接双击运行。`dist/` 为静态产物，历史 vanilla 文件保留但不再导入，避免误删已有工作。旧检查脚本只作为历史证据。

## 业务适配

- 各页面统一在同一工作台壳内，默认会议。左栏顶部用 Logo + EurekaLife 替换“你的工作空间”标题；只保留 ×，隐藏展开状态下的重复折叠按钮。菜单默认 220，折叠 56；Ask AI 默认 320。公开设置仍保留组件提供的调宽边界，拖拽与方向键、Home/End、Enter 可用。
- 会议页保留即时录音／录制会议／上传文件的顺序。即时录音默认麦克风、仅录音；普通会议先进入录制设置，默认包含系统声音。选择仅录音后直接开始；选择屏幕与音频后点击下一步，选择 Entire Screen / Application Window 及具体画面，确认后直接开始录制。采用合成 SVG 缩略图，不枚举本机窗口或申请录屏权限；画面选择页的返回设置、关闭和 Escape 均回到第一步并保留设置，不启动录制。第一步校验音源与权限，第二步校验画面。
- 会议及每日记录共用 Chat 业务组合，右栏贯穿整页。概览、模型库、设置与隐私页不渲染 Ask AI 入口和右栏；窄屏弹层遵循相同页面范围。页面切换、左右栏关闭不清空草稿或录制状态；重置与浏览器刷新清空演示数据。输入框 Enter 换行，发送由按钮或表单提交完成，不添加自定义 Enter 截获。
- 会中回答仅使用已出现的合成原文，不能引用未来台词。停止生成取消当前定时器；引用回到对应原文并移动焦点。行动项先审核，表单关闭后恢复未提交草稿，确认仅写原型内存。
- 记录、下载、配对、转写、AI 和错误恢复均为模拟。模型来源链接只有主动点击才打开；文件选择仅使用文件名，不读取内容。
- 窄于 760px 时通过 Modal 打开导航和 Ask AI。桌面仍采用标准组件的各区独立滚动与窄容器内部横向滚动；不会把多栏最小宽度强加到整个浏览器页面。
- 模态框保留 Escape、焦点约束与焦点返回；侧栏标准关闭按钮恢复到重开入口。菜单提示位于图标栏右侧。

状态标签通过业务 Tag 组合统一设置公开 `variant / shape / bg / c` 属性：圆角、浅色底、低饱和深色字，正常／警告／错误保留颜色语义，不再使用绿底白字。

## 初版验证记录（2026-11-12）

工作区未提交。类型与生产构建使用 `npm run build`；浏览器回归使用 `npm run test:ui`，最终运行针对 Vite 的生产产物预览（测试端口 8792，本地开发预览保持 8791）。结果保存在 [results.json](../verification/components/results.json)，脚本在 [check.cjs](../verification/components/check.cjs)。

最终结果：类型与生产构建通过；Chromium 153 下 13/13 组通过，零脚本错误、缺失资源、外部请求或网络写入。

覆盖 13 组检查：源文件哈希、真实组件样式与三个入口、图标栏和双侧调宽、仅音频跳过第二步、屏幕模式两步流程与返回草稿及窄屏、录制与 AI 边界、断连／延迟／总结失败重试、文件格式／示例导入、会议搜索收藏／引用／行动审核、知识库流程、模型与配对、六档宽度及移动弹层、浏览器错误与请求边界。六档宽度为 1600 / 1280 / 1024 / 768 / 390 / 320，逐一检查五个页面。

早期迁移曾因会议表头 JSX 缺少起始标签导致编译失败，修正后构建通过。初轮自动检查还暴露了测试定位器过度严格、收藏按钮与会议标题同名匹配、异步总结尚未完成时就断言等脚本问题；修正定位与等待后重新执行，初次失败不计为通过。视觉复查修正了折叠菜单图标被隐藏、会议副标题挤在同一行和品牌链接默认下划线。

合成页面截图保存在仓库外 `/private/tmp/eurekalife-mac-components/`。构建输出、node_modules 和临时截图不提交。生产浏览器验证不代表原生 Mac 录音、真实模型、iPhone 同步或硬件验收；真实中文输入法、物理触屏与 VoiceOver 未测试。本轮没有构建 Swift、安装 App、提交／推送 Git 或公网部署。

## 2026-11-13 设置、会议删除与每日记录

本轮按用户明确要求修改产品原型。继续沿用现有标准组件，未修改组件库源码或依赖。导航顺序为概览、模型库、会议、每日记录、知识库、设置；设置展开后包含主目录设置、隐私与说明。折叠图标栏保留六个入口，设置页内仍可切换两个分类。Ask AI仍只出现在会议和知识库。

主目录默认示例为`~/Documents/EurekaLife`，下设`Models`、`Meetings`、`DailyRecords`；目录变更需预览旧／新位置并确认，模拟迁移后更新三处路径显示，取消不变更。路径输入支持绝对路径或`~/`，不接受相对路径和上级跳转。下载、录制、整理、备份进行时不可更改。示例路径及迁移不访问真实文件系统，也不改变原生App配置。

会议列表新增删除图标和确认弹窗，说明录音／视频、原文、总结、对话一并删除。取消保留记录；确认清理该条示例及关联草稿。录制、暂停录制和整理中的会议不可删除；删掉当前会议后返回列表并清空对应对话。删除不影响每日备份。仅模拟列表删除，无真实文件删除。

每日记录面向EurekaLife App每日数据的Mac备份，区别于知识库的跨记录阅读与Ask AI。按日期显示已备份／待备份，查看录音、闪念、照片和回顾等示例；备份范围说明涵盖记事本、人物与地点及原始附件。显示设备状态、已备份天数／记录数和主目录下的备份位置。连接后可模拟备份最新数据；未配对、网络不可达或离线时保留历史浏览并阻止新备份，备份期间全局连接中断则取消本次模拟操作。跨页保留状态，刷新／重置清空。设备、日期和资料均为合成内容，不连接iPhone、不上传、不读取原生数据库。
