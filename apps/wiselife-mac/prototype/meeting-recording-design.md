## 参考与目标

用户提供的 `notta-4.jpg`、`notta-5.jpg`、`notta-6.jpg` 分别展示记录入口与列表、无机器人录制设置、实时转写与右侧 AI。参考其任务流程，沿用 EurekaLife 的浅灰／蓝灰配色、macOS 系统字体、细线图标与现有 Mac 导航。

补充参考 `notta-7.jpg` 的画面选择器：第一步为录制设置；仅当选择屏幕与音频时，第二步才选择 Entire Screen 或 Application Window 与具体画面。缩略图为合成示意，不复制用户截图中的私人窗口内容。

目标：用户在这台 Mac 上完成准备 → 录制 → 回顾 → 审核行动项，能够看清正在录什么、处理到了哪一步、AI 结论来自哪里。

本次选择独立「会议」入口：会议列表、会中原文和会后纪要在一处衔接。另一方案是继续扩展知识库内的单一「开始录音」按钮；入口更少，但会议的录制设置、状态和历史回顾会与每日记录混杂。本轮保留原知识库演示，后续原生设计再决定统一入口。

## 页面与交互

| 页面 | 内容 | 可体验的行为 |
| --- | --- | --- |
| 我的会议 | 即时录音、录制会议、上传文件、记录列表 | 三入口依次排列；搜索、收藏、全部／已收藏筛选、进入历史会议 |
| 文件导入 | 选择音视频、语言、模拟导入 | 检查扩展名，模拟整理并进入会议；仅使用文件名，不读取或上传内容 |
| 录制准备 | 会议名、仅录音／屏幕与音频、系统声音、麦克风设备、语言、翻译、权限 | 切换方式与音源、模拟权限未授权；条件不足时不能开始或进入下一步 |
| 画面选择 | Entire Screen / Application Window、缩略图、选中状态 | 默认应用窗口；未选择不能继续；切换分类清除临时选择；取消不开始录制 |
| 会中 | 原文／总结／行动项、说话人标签、右侧 Ask AI、底部录制条 | 示例原文逐段出现、暂停／继续、重点标记、引用回跳、翻译显示、AI 收起／展开 |
| 会后 | 整理中、已整理、失败状态、原文与纪要 | 查看有出处的讨论与决定、重试失败的总结、演示回放／拖动进度 |
| 行动审核 | 事项、负责人、计划时间 | 修改后确认加入示例待办，保留修改并防止重复加入 |

- 「录制会议」首先进入录制设置，系统声音和麦克风默认开启；仅录音点击开始即进入会中，没有画面选择步骤。屏幕与音频点击「下一步：选择画面」，选好画面后点击「开始录制」直接进入会中；「即时录音」直接进入设置，默认仅录音且只开麦克风。两种模式均至少需要一个音源；屏幕模式还需选画面。
- 系统声音是全系统范围，设置文案明确包含其他应用，不能暗示选择一个视频窗口就自动隔离该应用声音。实际应用级音源隔离另行验证。
- 画面选择分为 Entire Screen（2 个合成显示屏）与 Application Window（6 个合成应用窗口），均单选；选中后高亮并显示勾选。画面页的「返回设置」、关闭按钮与 Escape 均回到第一步，保留会议名称、模式、音源与语言等草稿，且不开始录制。可在第一步切回仅录音以跳过画面选择。整个屏幕提示其他窗口与通知也会被录入；应用窗口范围仅指画面，不暗示音源自动隔离。真实开发拟使用 macOS 系统选择器。
- 语言可选中文、英文、日文和中英双语；翻译可选目标语言。此处只演示设置，正文始终为固定中文样例，译文为固定英文样例，不声称已完成多语言识别。
- 原文每 6 秒出现下一段，共 6 段。暂停停止计时与新段出现；切换导航不结束会议，提供悬浮返回／暂停控件。
- 只允许同时进行一场会议。返回当前录制保持 AI 草稿与会话；正文更新不会清空正在输入的文字。
- Ask AI 是会议页面的整高右侧栏，与中间区域平级；首页和详情页都保留。未选会议时提示先选择会议；从详情返回列表仍明确显示当前会议范围，点击引用可返回原文。
- 左侧导航和右侧 Ask AI 都提供可访问的折叠图标。左侧键盘折叠到 56px 图标轨道，保留全部菜单与原生名称提示；右侧收起后，中间区域占用释放的宽度，顶部图标可重新展开。切换页面保留折叠状态；折叠不清空草稿、对话或中断录制。窄屏原型保留可折叠的紧凑菜单。
- 上传入口可选择 MP3／M4A／WAV／MP4／MOV，也可使用示例文件。只显示所选文件名并演示整理，原文始终来自固定样例；不读取文件内容。
- Ask AI 使用当前会议已经显示的样例片段。尚未讨论到的决定与行动项不提前生成。自由问题会说明这是固定演示，避免伪装真实模型回答。
- 结束录制需要确认；随后演示整理进度。转写延迟的片段在结束时补齐示例原文，再生成总结。
- 行动项加入只更新本页状态，不能显示为已创建系统提醒或发送给他人。

## 异常与恢复

| 触发 | 页面表现 | 恢复方式 |
| --- | --- | --- |
| 未授权 | 设置中提示所需权限，开始按钮不可用 | 模拟授权；不打开真实系统权限面板 |
| 无音源／未选画面 | 对应开始条件不可用 | 启用音源／选择示例窗口 |
| 麦克风断开 | 本轮采用暂停整个录制的保守设计，计时停止 | 切回内置麦克风并继续 |
| 转写延迟 | 录制计时继续，原文暂不增加 | 恢复后补齐，已有内容保留 |
| 总结失败 | 原文可读、纪要显示失败与原因 | 手动重新整理 |
| LLM 未加载 | AI 输入区显示未就绪，发送不可用 | 模型库加载后返回；录制不依赖 LLM |

右下方的演示状态选择器仅用于评审；原生 App 不需要此控件。模态框支持 Escape 关闭与焦点回还；长表单底部操作固定可见。7 种宽度适配仅方便浏览器评审，不改变 Mac 平台定位。

## 实现边界

本次仅修改 `prototype/` 的浏览器原型。当前已采用 React / TypeScript 与指定标准组件库，见 [组件迁移说明](docs/component-migration.md)。没有调用麦克风、屏幕录制、系统音频、ASR、LLM、文件系统存储、日历／提醒或网络写接口。示例人物、台词、时间与录制画面不是真实会议。状态只保存在页面内存，刷新或顶部重置会清空。

产品提议是本机保存音视频与原文、沿用用户选择的模型设置；现有 Mac Companion 的原生模型服务、数据存储及 API 能力不因原型而改变。原生开发需另行验证权限、双音源混音与回声、耳机切换、视频编码、长会议分段与恢复、模型调度、真实说话人识别和 SQLite 持久化。实时翻译与多语言能力不由本原型保证。

不包含机器人入会、第三方会议账号连接、链接导入、云端分享、云录制拉取或自动创建／发送任务。
